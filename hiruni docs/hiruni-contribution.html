Security Report · SE4030

Menu & Cart Services — from Vulnerable to Hardened

Full security assessment of the menu-service and cart-service — the two services I contributed to the Platoo food-delivery platform, plus the related front-end pages (menu browsing, cart page, restaurant-admin menu management). In this report I document how I discovered 15 distinct vulnerabilities (including 3 Critical and 5 High issues) using white-box review, black-box dynamic testing and security scanners — and how each in-scope issue was fixed.

Black-box Testing

HTTP-level functional & attack tests against real Express apps on disposable MongoDB databases. Written first as defect-detecting evidence, then flipped to assert the secure post-fix behaviour.

cart-service           23       17       6
                 ATTACK SURFACE
  • Missing auth → writes accepted (VULN-01/02)

  • $ne NoSQL bypass on userId          (VULN-05)
  • HTML upload accepted / Host inject  (VULN-06/10)
