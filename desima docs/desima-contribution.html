06

Identified but Not Fixed

And the honest reasons why
NF-1 Credential rotation for previously committed secrets
The Gmail app password & MongoDB URIs exposed before (SRCH-08 / NOTIF-07) must be rotated/revoked. Not a code fix — an operator action: regenerate the app password and DB access strings and re-inject via a secret manager. Flagged in the manifest comments.
NF-2 Out-of-scope sibling microservices (17 gitleaks hits remain)
cart / menu / delivery / admin / order / stripe / user manifests still contain real-looking credential material. Out of scope for this contribution (search + notification + frontend). The gitleaks allowlist covers only the two assessed manifests; siblings are a cross-team follow-up.
NF-3 Dockerfiles run as root / NODE_ENV=development
Semgrep's default rule pack flagged a container without a USER directive. These are local dev images (npm run dev), not the deployment path; a production multi-stage image (USER node) would alter the dev workflow — deferred.
NF-4 Per-recipient retry queue for e-mail fan-out
Current design counts delivered/failed and fails loudly (Promise.all one-shot). A durable queue with retries is an architectural change beyond the sandbox requirement — documented follow-up.
NF-5 Hardening of the other microservices
Rate limiting / CORS / headers / input validation for user, menu, order, etc. are out of scope — a team project where each member owns a subset of services. Listed as cross-team follow-up.
07

Best Practices that would have prevented these

Software-engineering process, not just patches
A03
01
Validate input at the boundary

Never trust req.*. Enforce types, lengths and ranges before values reach a DB query or e-mail template.

A03
02
Escape before interpolation

Regex-escape before $regex; keep user text out of SMTP headers and templates (fixed subject/from).

A01
03
Default-deny everywhere

CORS by allow-list, JWT algorithms pinned, roles checked at middleware, secrets referenced by name only.

A07
04
Never commit secrets

Env / secret-manager / Helm only; a gitleaks pre-commit hook would have blocked SRCH-08 & NOTIF-07 at the gate.

A05
05
Bound every resource

Pagination caps, recipient caps, rate limits, maxTimeMS query timeouts.

A05
06
Fail loudly, generically to clients

Central error handler: static messages out, full details into server logs only.

A05
07
Security headers from day one

Helmet + disabling X-Powered-By belong in the first middleware of any Express app.

CI/CD
08
SAST + SCA + tests in CI

Fail the build on npm audit > 0, Semgrep/gitleaks findings and black/white-box regressions.

Testing
09
Assert secure behaviour

Write tests that demand 400-not-500, no reflection and no stack traces, so regressions cannot silently return.
